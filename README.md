
# Data Science Salary Analysis Dashboard

## Project Overview

This project analyzes data science job salary data using Python, Pandas, Matplotlib, and Power BI.

The objective is to identify salary patterns based on job title, experience level, company size, employment type, work year, and company location.

## Tools & Technologies

- Python
- Pandas
- Matplotlib
- Power BI
- CSV Dataset

## Project Workflow

Dataset → Data Cleaning → Exploratory Data Analysis → Visualization → Power BI Dashboard → Insights

## Analysis Performed

- Analyzed salary distribution across different job titles.
- Compared average salaries across experience levels.
- Analyzed salary differences by company size.
- Compared employment types.
- Studied salary trends from 2020 to 2024.
- Analyzed average salary across company locations.

## Power BI Dashboard

The interactive dashboard contains:

- KPI Cards
- Average Salary by Job Title
- Average Salary by Experience Level
- Average Salary by Company Size
- Average Salary by Employment Type
- Average Salary by Work Year
- Average Salary by Company Location
- Interactive slicers for filtering the dashboard

## Key Insights

- Salary varies across different data science job roles.
- Higher experience levels generally have higher average salaries.
- Company size and employment type show differences in salary levels.
- Salary levels changed across the years.
- Company location is an important factor in salary differences.

## Conclusion

This project demonstrates how Python can be used for data analysis and Power BI can be used to create an interactive dashboard for presenting meaningful business insights.
